# Fickle FOSS Tracker

For use with the Fickle FOSS app (https://github.com/benopotamus/fickle-foss). Records the dates that apps are used. Fickle FOSS uses this app-date data to populate its list of apps to donate to.

Tracker also provides Fickle FOSS with app icons by creating a Flatpak accessible icons cache. This allows the Flatpak version of Fickle FOSS to display app icons for apps installed via package managers (zypper, apt-get, etc).

# Installation

You can install this extension from Gnome Extensions

https://extensions.gnome.org/
